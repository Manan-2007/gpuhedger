## Units (read this before any maths)

- **USDC amounts and all prices are 6-decimal integers.** `$2.20` = `2_200_000`; `$0.035` = `35_000`. [CODE: MockUSDC.sol `decimals()`]
- Prices are **per GPU-hour**. Total = price × `contractSize` × contracts (all raw, so the result is in 6dp USDC).
- `contractSize` and contract counts are plain integers.
- Volatility is in **basis points** (4200 = 42%).
- Timestamps are unix **seconds** (`uint256`).
- `underlying` and `region` are `bytes32` ASCII, right-padded with zeros (`stringToHex("H100", {size: 32})`).
- `optionType`: `0 = Call`, `1 = Put`. Futures `side`: `0 = Long`, `1 = Short`.
- `PositionStatus`: `0 Open, 1 Exercised, 2 Expired, 3 Claimable`. `ActivityKind`: `0 SeriesCreated, 1 Purchase, 2 Exercise, 3 Expire, 4 Claim`.
- ghLP vault shares have 6 decimals.

`SeriesParams = {underlying bytes32, region bytes32, optionType uint8, strikePrice, expiration, contractSize, premium, maxPayoutPerUnit, maxContracts, oracle, settlementToken}`. Validation: strike > 0; now < expiration ≤ now + 730 days; 1 ≤ contractSize ≤ 1,000,000; cap > 0; for puts cap ≤ strike; 0 < premium < cap; maxContracts > 0; oracle and token approved; oracle supports the underlying. [CODE: OptionFactory.sol `_validate`]

`OptionDetails` fields: `seriesId, option, underlying, region, optionType, strikePrice, expiration, contractSize, premium, maxPayoutPerUnit, maxContracts, soldContracts, openContracts, exercisedContracts, collateralPerContract, collateralBalance, lockedCollateral, totalPaidOut, settlementToken, oracle, writer, factory, createdAt, settled`. Available = `maxContracts − soldContracts`. Open interest = `openContracts`.

`Activity = {kind, seriesId, account, contracts, amount, timestamp, blockNumber}`. `amount` = premium (Purchase), payout (Exercise/Claim), collateral (SeriesCreated), released collateral (Expire). Event `ActivityRecorded(kind indexed, seriesId indexed, account indexed, amount)` is emitted for each, which is how the UI finds tx hashes.
