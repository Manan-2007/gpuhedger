## Known bugs and tech debt

1. **Fallback prices masquerade as oracle prices** on Trade, MarketDetail and the payoff chart's "Oracle $x" label when the oracle read fails. Fix: show an "Oracle unavailable" state and disable trading. [CODE: hooks/useOracle.ts]
2. **Exact-amount approvals** mean every buy needs two wallet confirmations. [CODE: TradePanel.tsx] See decision Q7.
3. **No route code-splitting**: the 553 kB charts chunk loads on the landing page. Use `React.lazy` per page.
4. **No WalletConnect**: on mobile, only in-wallet browsers (MetaMask app) can connect. [CODE: lib/wagmi.ts]
5. **Portfolio totals ignore futures and vault shares.**
6. **Activity feed ignores futures trades** (the factory doesn't record them). [CODE: ComputeFutures.sol]
7. AdminPage is a 600-line file with four panels. Split it.
8. `lib/viem.ts` is dead code.
9. Untested UI paths (see the status table in `01-…`): claim, futures settle, vault withdraw/harvest, admin create series/market, pause, vol update, real MetaMask, wrong-network switch.
10. `formatTenor` rounds (29.6 days shows "30D"), which is fine for display but the detail page should show the exact date. It already does.
